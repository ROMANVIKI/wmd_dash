Breeder Farm Expense = Daily Ops Feed Cost + Breeder Dept Workers (GHC80K/wk) + Op Requests
Cost/Egg = Breeder Farm Expense ÷ Hatchable Eggs
Selling Px/Egg = Cost/Egg × 1.66  (66% margin)



Hatchery Input = Egg Selling Price × Eggs Set
Hatchery Total = Hatchery Input + Hatchery Dept Workers (GHC110K/wk)
Cost/Chick = Hatchery Total ÷ Good Chicks
Selling Px/Chick = Cost/Chick × 1.40  (40% margin)
Profit/Chick = Selling Px - Cost
